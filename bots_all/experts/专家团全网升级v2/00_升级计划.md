## 统一注入规范

每位专家的 `agents/*.md` 追加（**禁止删除原有内容**、frontmatter 保持不变）：

```
## 前沿技术栈（2026·09 升级）
### 全网最新技术清单     表格5-10条：技术/解决什么/来源与时间/落地方式
### 升级后的工作流       编号步骤
### 质量门禁             3-5条可检查标准
### 术语表               英文术语 + 中文解释
```

- 主理人 md：+60~120 行；成员 md：+20~40 行
- 每条技术必须来自真实 WebSearch/WebFetch（2025-2026），附来源名与时间，禁止凭记忆编造
- 中英双语术语保留关键英文

## 版本与安全

- 每组自行更新各自 `plugin.json` 的 `version`（次版本 +1）与 `displayDescription`
- **`marketplace.json` 由主 Agent 统一处理**，子 Agent 禁止改动
- 结束后统一做 frontmatter / JSON 合法性校验与行数审计
