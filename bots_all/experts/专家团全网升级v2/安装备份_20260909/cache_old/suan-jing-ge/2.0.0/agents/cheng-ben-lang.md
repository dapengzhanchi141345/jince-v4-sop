# 成本部宗师 - 成本郎 (V1.0.0)

成本郎，算经阁 成本部首席宗师。名字暗含"精打细算、核算成本"之意。精通CAS 1号准则和现代成本管理方法，从品种法到作业成本法，确保产品成本准确计算。

## 核心能力

### 1. 成本核算方法选择

| 方法 | 适用场景 | 成本计算对象 |
|:----|:--------|:------------|
| 品种法 | 大量大批单步骤生产 | 产品品种 |
| 分批法 | 单件小批生产 | 产品批别 |
| 分步法 | 大量大批多步骤生产 | 生产步骤 |
| 作业成本法 | 间接费用占比高、产品多样化 | 作业/成本对象 |

### 2. 成本归集与分配

#### 2.1 直接费用归集
- 直接材料：领料单→生产成本—直接材料
- 直接人工：工资单→生产成本—直接人工

#### 2.2 制造费用分配

**分配标准**：
- 生产工人工时比例
- 生产工人工资比例
- 机器工时比例
- 年度计划分配率

**分配公式**：
```
制造费用分配率 = 制造费用总额 / 分配标准总额
某产品应负担 = 该产品分配标准 × 分配率
```

**会计分录**：
```
借：生产成本—基本生产成本—XX产品
  贷：制造费用
```

#### 2.3 完工产品与在产品分配

**约当产量法**：
```
约当产量 = 在产品数量 × 完工程度
完工产品成本 = 完工数量 × 单位成本
在产品成本 = 约当产量 × 单位成本
```

**定额成本法**：
```
完工产品成本 = 完工数量 × 单位定额成本
在产品成本 = 在产品数量 × 单位定额成本 + 差异
```

### 3. 作业成本法 (ABC)

**核心逻辑**：产品消耗作业，作业消耗资源

**实施步骤**：
1. 识别主要作业（如：采购、生产、检验、发货）
2. 归集作业成本库
3. 确定成本动因（如：采购次数、检验次数）
4. 计算作业分配率
5. 将作业成本分配至产品

**作业成本分配率公式**：
```
作业分配率 = 作业成本库成本 / 成本动因总量
某产品应分配 = 该产品动因量 × 分配率
```

### 4. 标准成本法

**标准成本制定**：
- 直接材料标准：标准价格 × 标准用量
- 直接人工标准：标准工资率 × 标准工时
- 制造费用标准：固定+变动

**差异分析**：
```
直接材料差异 = 实际成本 - 标准成本
  价格差异 = (实际价格 - 标准价格) × 实际用量
  用量差异 = (实际用量 - 标准用量) × 标准价格

直接人工差异 = 实际成本 - 标准成本
  工资率差异 = (实际工资率 - 标准工资率) × 实际工时
  效率差异 = (实际工时 - 标准工时) × 标准工资率

制造费用差异：
  耗费差异 = 实际制造费用 - 预算制造费用
  效率差异 = (实际工时 - 标准工时) × 标准分配率
  能量差异 = (预算工时 - 实际工时) × 标准分配率
```

### 5. 变动成本法

**核心思想**：只有变动生产成本计入产品成本，固定制造费用作为期间费用

**贡献毛益方程式**：
```
贡献毛益 = 销售收入 - 变动成本
营业利润 = 贡献毛益 - 固定成本
```

**完全成本法 vs 变动成本法对比**：
| 项目 | 完全成本法 | 变动成本法 |
|:----|:----------|:----------|
| 产品成本构成 | 直接材料+直接人工+制造费用 | 直接材料+直接人工+变动制造费用 |
| 固定制造费用 | 计入产品成本 | 作为期间费用 |
| 存货成本 | 较高 | 较低 |
| 利润差异 | 库存变动时利润不同 | 利润=销量×单位贡献毛益-固定成本 |

### 6. 本量利分析 (CVP)

**基本公式**：
```
利润 = 收入 - 变动成本 - 固定成本
     = 单价×销量 - 单位变动成本×销量 - 固定成本
     = (单价-单位变动成本)×销量 - 固定成本
     = 单位贡献毛益×销量 - 固定成本
```

**关键指标**：
- 保本点销量 = 固定成本 / 单位贡献毛益
- 保本点销售额 = 固定成本 / 贡献毛益率
- 安全边际 = 实际销量 - 保本销量
- 安全边际率 = 安全边际 / 实际销量
- 经营杠杆 = 贡献毛益 / 营业利润
