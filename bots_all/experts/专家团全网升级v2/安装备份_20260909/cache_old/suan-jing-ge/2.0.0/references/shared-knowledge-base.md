## 5. 财务分析框架

### 5.1 五大能力分析
1. **偿债能力**：流动比率、速动比率、现金比率、资产负债率、产权比率
2. **盈利能力**：销售毛利率、销售净利率、ROE、ROA、EPS
3. **运营能力**：应收账款周转率、存货周转率、总资产周转率
4. **成长能力**：营业收入增长率、净利润增长率、总资产增长率
5. **现金流量能力**：销售现金比率、全部资产现金回收率

### 5.2 杜邦分析体系
```
ROE = 销售净利率 × 总资产周转率 × 权益乘数
```

### 5.3 盈利质量评估
- 经营现金流/净利润 > 1：盈利质量高
- 非经常性损益占比 < 20%：盈利可持续
- 应收/存货增速 < 收入增速：盈利含金量高

### 5.4 财务预警模型
- Altman Z-Score（制造业）
- F分数模型（多因素）

## 6. 成本管理框架

### 6.1 成本核算方法
- 品种法：大量大批单步骤生产
- 分批法：单件小批生产
- 分步法：大量大批多步骤生产
- 作业成本法：间接费用分配

### 6.2 成本性态分析
- 变动成本：随产量正比例变动
- 固定成本：不随产量变动
- 混合成本：分解为固定+变动

### 6.3 本量利分析
```
利润 = 收入 - 变动成本 - 固定成本
保本点销量 = 固定成本 / (单价 - 单位变动成本)
安全边际 = 实际销量 - 保本销量
```

## 7. 合并报表框架

### 7.1 控制判断三要素
1. 拥有对被投资方的权力
2. 通过参与被投资方相关活动而享有可变回报
3. 有能力运用权力影响回报金额

### 7.2 抵销分录类型
1. 母公司长期股权投资与子公司所有者权益抵销
2. 母公司投资收益与子公司利润分配抵销
3. 内部债权债务抵销
4. 内部交易未实现利润抵销
5. 内部交易固定资产抵销

### 7.3 合并程序
1. 统一会计政策和会计期间
2. 将对子公司的长期股权投资由成本法调整为权益法
3. 编制抵销分录
4. 计算合并金额
5. 编制合并工作底稿
