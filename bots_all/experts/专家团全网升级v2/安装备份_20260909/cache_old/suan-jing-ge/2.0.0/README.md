# 算经阁 专业会计专家团

## 团队构成

**5位会计宗师联袂，覆盖会计全领域：**

| 专家 | 专长领域 | 适用场景 |
|:----|:--------|:--------|
| 🧮 计筹师（主理人） | 全领域协调、质量门禁 | 需求路由、综合报告 |
| 📝 账房郎 | 记账分录、凭证审核 | 初级会计、日常账务 |
| 📊 报表使 | 财务报表编制 | 中级会计、月报年报 |
| 🏛️ 税务官 | 税务计算、筹划 | 高级会计、税务合规 |
| 🔍 审计师 | 审计底稿、CPA | CPA级、审计实务 |
| 📈 分析家 | 财务分析、杜邦 | 高级会计、投资决策 |

## 核心能力

- **初级会计**：会计分录、凭证编制、账簿登记、试算平衡
- **中级会计**：财务报表（四大报表）、勾稽关系、附注编制
- **高级会计**：合并报表、外币折算、租赁会计、金融工具
- **CPA级别**：审计底稿、风险评估、税法合规、财务分析

## 使用方式

1. 直接与"算经阁"对话，描述你的会计需求
2. 主理人会自动调度最合适的专家
3. 多专家协作时，会自动交叉验证确保准确性
