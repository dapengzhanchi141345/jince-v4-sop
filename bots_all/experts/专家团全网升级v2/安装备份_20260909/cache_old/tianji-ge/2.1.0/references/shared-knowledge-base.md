## 一、阴阳 — 万物之根本原理

**核心法则**：
- 阴阳对立：天地/日月/昼夜/男女/寒暑/动静/刚柔
- 阴阳互根：阴中有阳、阳中有阴（太极图）
- 阴阳消长：阳极生阴、阴极生阳（物极必反）
- 阴阳转化：阴阳平衡为吉、阴阳失衡为凶

**在各领域的体现**：
- 八字：日干阴阳决定顺逆大运方向
- 紫微：南派(阳)与北派(阴)分析方法不同
- 六爻：老阴/老阳为动爻、少阴/少阳为静爻
- 风水：阴宅(阴)与阳宅(阳)使用不同理论
- 择日：阳事择阳日、阴事择阴日
- 姓名：男性宜阳刚、女性宜柔美

## 六、跨方法综合研判协议（所有部门必须遵守）

### 6.1 各方法的最佳适用场景

| 方法 | 最适合 | 不太适合 | 特点 |
|------|-------|---------|------|
| **八字（子平）** | 一生格局/长期运势/性格 | 具体事件的精确时辰 | 定调长久态势 |
| **紫微斗数** | 十二宫领域细分/流年 | 无具体出生时间时 | 宫位细密 |
| **六爻** | 一事一测/具体吉凶 | 抽象大问题 | 精准实用 |
| **奇门遁甲** | 出行/谈判/择时/商业 | 测日常琐事 | 时空合一 |
| **梅花易数** | 快速推断/趋势/方向 | 需要精确数据的场景 | 灵活快速 |
| **风水** | 空间环境/布局调整 | 纯人事问题 | 环境决定论 |
| **姓名学** | 起名改名/数理评估 | 性格深度分析 | 数理为主 |
| **相术** | 当面看人/性格/健康 | 无照片/无描述 | 直观外显 |
| **🆕 父母星法** | 父母缘/父母健康/祖荫 | 无八字信息时 | 六亲口诀 |
| **🆕 子女星法** | 子女缘/生育时机/教育 | 未成年子女定性 | 食伤体系 |
| **🆕 祖荫风水** | 家族传承/祖先福荫 | 无祖坟信息 | 风水+八字交叉 |

### 6.2 多方法结论冲突时的处理原则（优先级）

**原则一：共性优先于特性**
多方法给出同一结论 → 可信度最高
双方法一致 → 可信度高
单方法得出且与其他方法不矛盾 → 可信度中等
单方法得出但与其他方法矛盾 → 需标记争议

**原则二：按领域划分优先级**
- 测命运格局 → 八字 > 紫微 > 相术 > 六爻
- 测具体事件 → 六爻 > 奇门 > 梅花 > 大六壬
- 测空间环境 → 风水 > 奇门
- 测时间择吉 → 择日 > 奇门 > 六爻
- 测姓名 → 姓名学（唯一）
- 测人际关系 → 大六壬 > 紫微 > 六爻
- **🆕 测父母缘/健康 → 八字父母星 > 紫微父母宫 > 相术日月角**
- **🆕 测子女缘/生育 → 八字子女星 > 紫微子女宫 > 占卜**
- **🆕 测亲子关系 → 紫微子女宫+父母宫 > 八字 > 六爻**
- **🆕 测祖荫家运 → 八字年柱 > 风水祖坟 > 紫微**

**原则三：当同一领域内不同方法冲突时**
- 八字内部（子平 vs 滴天髓 vs 穷通宝鉴）→ 普通格局：调候为主、扶抑为辅；**建禄格/月劫格特殊规则：格局派优先——官杀制劫为先**（《子平真诠》顺用法），调候次之，扶抑再次之。口诀：「身旺格调候为先，建禄劫格格为先」
- 紫微内部（三合 vs 飞星 vs 四化）→ 三合定格局、四化定应期、飞星定轨迹
- 风水内部（形势 vs 理气）→ 形势为主（峦头不正，理气再好也减分）
- 相术内部（面相 vs 手相 vs 骨相）→ 骨相定格局、面相定时运、手相定细节

**原则四：实战优先于学术争议**
如果某种方法在相似案例中已多次验证，优先采信该方法的结论，即使学术上另有争议。

### 6.3 综合报告输出规范（多部门参与时）

一份高质量的综合报告应当包含：

1. **问题重述**：用户问了什么，涉及哪些领域
2. **方法说明**：用了哪几种方法，为什么选这些方法
3. **逐项结论**：每个方法得出的结论，包含排盘/起卦/盘局等完整依据
4. **共识部分**：多方法一致的结论，用"各部门一致认为"标注
5. **争议部分**：有分歧的结论，用"XX部认为…而XX部认为…有待商榷"标注
6. **综合研判**：主理人的综合评估和最终建议

### 10.2 缺失/异常数据的降级策略

当某部门所需的输入数据不可用时，必须按以下协议降级运行，**严禁直接报错或拒绝服务**：

| 场景 | 理想情况 | 降级方案 A | 降级方案 B | 降级方案 C |
|------|---------|-----------|-----------|-----------|
| **缺少出生时辰** | 完整四柱排盘 | 用年月日三柱+子时推算（标注"时柱为估算"） | 用年月日三柱+午时推算（标注"时柱为假设"） | 改用紫微斗数（相对不依赖时辰的精确性） |
| **缺少出生年份** | 排八字 | 无八字 → 询问生肖（至少确定年支） | 无生肖 → 改用占卜（六爻/梅花，不依赖八字） | 无任何信息 → 引导用户至少提供一个参考点 |
| **缺少出生月日** | 排八字 | 有年份+时辰 → 用紫微斗数（推月日相对影响较小） | 有年份→ 改用姓名学/相术（完全不依赖生日） | 用占卜替代 |
| **缺少父母八字** | 分析父母星完整信息 | 有命主八字即可分析父母星 | 有父母生肖 → 简化父母关系判断 | 完全无信息 → 改用六爻占卜问父母 |
| **缺少子女八字** | 分析子女星完整信息 | 有命主八字即可分析子女星 | 有子女生肖 → 简化子女关系判断 | 完全无信息 → 改用梅花/六爻占卜问子女 |
| **缺少照片** | 相术分析可用 | 无照片 → 转向八字+紫微综合看外表特征 | → 放弃相术，使用其他方法补充 | - |
| **缺少房屋坐向** | 完整风水分析 | 无准确坐向 → 用小区大致方位 | 无任何方位 → 改用卦象/八宅命卦分析 | 建议用户提供更多信息后重测 |
| **缺少出生地** | 真太阳时校准 | 用北京时间（标注"未做真太阳时校正"） | 用东八区默认时间 | - |

**降级报告的标注规则**：
- 所有降级方案输出的报告必须在醒目位置标注：`⚠️ [数据降级] 因缺少____，本报告基于____推算，精度为____级`
- 精度等级：`A级（完整数据）→ B级（有部分推测）→ C级（多处推测）→ D级（仅作参考）`
- 主理人汇编时必须检查降级标注，并在综合报告中向用户说明

### 10.4 结论冲突时的消解协议（扩展版）

当两个或多个部门的结论不一致时，按以下协议消解：

```
级别0：完全一致 ✓
  全部部门结论一致 → 直接采用，标注"高度可信"

级别1：趋势一致，细节有出入
  如八字说"今年财运佳"，六爻说"今年求财有机会但有波折"
  → 共识：今年财运向好；出入：顺利程度不同
  → 报告写法："各部一致认为财运向好。命理部认为较为顺利，占卜部提示有小波折"

级别2：领域内分歧
  如子平说"用神为木"，滴天髓说"用神为火"
  → 调候优先原则：检查季节调候需求
  → 报告写法："命理部两种方法有分歧——子平法认为用木（扶抑），滴天髓认为用火（调候），
     鉴于生于夏季，优先采信调候需求，以火为断"

级别3：跨领域根本冲突
  如八字说"事业大吉"，六爻说"近期事业凶"
  → 八字管"定数"（长期格局），六爻管"变数"（短期事件）→ 两者并存
  → 报告写法："八字显示本年度事业运处于上升通道（长期定数），
     六爻显示当前月份有阻力（短期变数），建议谨慎过渡后积极布局"

级别4：不可调和的分歧
  如八字说"适合创业"，风水说"办公室风水极差"
  → 报告需明确标注争议，并提出"待进一步验证"的建议
  → 可以在不同场景下分别遵循：创业方向以八字为准，办公地点以风水为准
```

### 10.7 稳定功能保障：六大稳定性规则

> 以下六大规则确保天机阁在任何输入条件下的稳定输出。

**规则一：永不报错，总有方案**
即使某部门所需的输入数据完全不可用，也必须提供降级方案（参考10.2节）。
禁止行为：❌ "数据不足，无法分析" / ❌ "请提供完整信息"
正确行为：✅ "因缺少___，改用___方法分析，精度为___级。如需更精确结果，请提供___"

**规则二：每个结论必须有出处**
所有核心断语必须注明古籍出处或方法依据。
禁止行为：❌ "你今年运势不错"（无依据）
正确行为：✅ "你今年进入甲木正印大运，《渊海子平》云'印绶格以官为用'，今年官星透干…"

**规则三：争议必须标记，不可掩盖**
当两个部门的结论不一致时，必须在综合报告中分别列出，标注"不一致"。
禁止行为：❌ 只写一个结论，隐藏另一个部门的分析
正确行为：✅ "命理部认为…而占卜部认为…，两者在XX方面有分歧"

**规则四：边界明确，不越界承诺**
- 不可替代医疗建议
- 不可替代法律意见
- 不可对未成年子女下"命运定性"断语（只给趋势和建议）
- 不可保证"100%准确"或"绝对会发生"
- 生育建议不可承诺"一定生男/生女"

**规则五：信息不全时主动引导，而非终止**
当用户信息不全时，给出当前能做的最好分析，同时告知"如果补充___信息，可以进一步分析___"。

**规则六：输出一致性保障**
相同输入条件下（同一八字/同一问题/同一时间）必须输出一致的结论框架。
- 同一八字 → 相同的大运排法、相同的用神判断
- 同一卦象 → 相同的六亲生克、相同的吉凶判断
- 同一房屋 → 相同的坐向、相同的飞星分布
