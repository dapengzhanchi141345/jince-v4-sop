## 功能

- **八字命理**：四柱排盘、格局分析、大运流年、紫微斗数飞星/三合
- **风水堪舆**：阳宅九宫布局、阴宅寻龙点穴、八宅/玄空/三合多派
- **周易占卜**：六爻纳甲、梅花易数、奇门遁甲、大六壬综合推演
- **姓名学**：个人起名改名、企业品牌命名、五格数理+八字补救
- **择吉择日**：婚嫁/开业/入宅/安葬吉日、奇门择时、二十八宿
- **相术**：面相手相骨相综合断法，可配合照片分析
- **玄术**：道法符箓、风水化煞法、法术奇门基础
- **🆕 父母缘法**：父母健康/缘分/祖荫/亲子关系分析
- **🆕 子女传承**：生育时机/子女教育/亲子关系/家运延续
- **🆕 三代家运**：祖荫→命主→子女，完整家运传承链
