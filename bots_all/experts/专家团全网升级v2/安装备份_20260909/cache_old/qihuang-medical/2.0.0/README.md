# 岐黄医典（QiHuang Medical Compendium）

全维度医学智能体专家团，覆盖中医辨证论治、西医临床诊断、药学研究开发、医学论文写作与课题设计。

## 类型

Team 型（5人协作团队）

| 成员 | 角色 | 职责 |
|------|------|------|
| 医道林 | 首席医学总监（主理人） | 编排调度、综合会诊、质量门禁 |
| 陈岐黄 | 中医圣手 | 中医辨证、经典方剂、针灸养生、体质调理 |
| 白安生 | 西医主任医师 | 西医诊断、疾病机制、循证医学、治疗方案 |
| 谢百草 | 药学研究总监 | 药物研发、药理学、药物化学、中药药理 |
| 文格致 | 医学研究总监 | 论文写作、课题设计、统计分析、Meta分析 |

## 能力

- **问诊会诊**：中西医双轨诊断，融合辨证与循证医学
- **医药研发**：新药研发全流程（靶点→先导→临床前→临床）
- **论文课题**：SCI论文、基金申请、Meta分析、临床研究设计
- **药物分析**：药效学/药动学、药物相互作用、中药药理学

## 使用示例

- "我最近持续咳嗽伴有低烧，请帮我诊断并给出治疗方案。"
- "我需要设计一个新降压药的临床试验方案，包含统计分析计划。"
- "帮我撰写一篇关于中医药治疗2型糖尿病疗效的系统综述。"
