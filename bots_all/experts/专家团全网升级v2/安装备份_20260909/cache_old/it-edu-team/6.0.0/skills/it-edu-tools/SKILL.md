# 信息科技教学全栈工具集 V2.0

本 Skill 提供初中信息科技教学中常用的可执行工具和模板，覆盖教学团全部6个角色的常用工具。

## 工具清单（V2.0新增3个）

### 1. 教案生成器
- 根据课题+年级+课标要求，自动生成标准教案
- 输出格式：Markdown结构化文档
- V2.0升级：支持PBL/5E/探究式等多种教学法模板
- 用法：提供课题、年级、课时数、教学法偏好、是否区分分层

### 2. 代码批改器
- 输入学生代码+题目要求，自动检查并给出批改意见
- 检查项目：语法错误、逻辑错误、命名规范、代码风格、安全漏洞
- 输出：逐行评价+综合评分+改进建议+最佳实践
- V2.0升级：新增JavaScript/HTML代码批改支持

### 3. 双向细目表生成器
- 根据知识点列表和题量，自动生成试卷蓝图
- 支持调整难度分布和题型配比
- V2.0升级：新增新题型（拖拽/排序/输出预测）配比选项

### 4. 学情报告生成器
- 输入各题得分率，生成班级学情分析
- 输出：知识点掌握热力图、学习路径推荐、分层教学建议、典型错题归因
- V2.0升级：新增知识图谱归因分析

### 5. 分层作业设计器
- 根据知识点生成三级难度作业（基础/进阶/挑战）
- 含答案和解析
- V2.0升级：新增个性化作业（按学生画像）

### 6. 课件模板生成器（V2.0新增）
- 根据教案自动生成HTML课件模板
- 可选风格：科技蓝/护眼绿/简约灰/卡通彩
- 输出：单文件HTML，直接开箱即用
- 用法：提供教案文本、风格偏好、是否需交互组件

### 7. STEM项目设计器（V2.0新增）
- 根据学科组合+主题自动生成跨学科项目方案
- 输出：驱动问题→任务链→评价量规→资源清单
- 用法：提供年级、融合学科、项目主题、周期

### 8. 课程质量门禁检查器（V2.0新增）
- 自动检查教案/试题/代码是否符合课标和质量标准
- 检查维度：格式完整性、课标对齐度、课堂可用性
- 输出：通过/待改进/未通过 + 具体改进建议

## 使用方式

在对话中直接提出需求即可，本 Skill 会自动判断调用哪个工具。

### 典型用法

```
用户: "帮我生成一份七年级《互联网应用与创新》的教案，2课时"
→ 调用教案生成器

用户: "帮我批改这段Python代码"
→ 调用代码批改器

用户: "出一份八年级Python期中试卷"
→ 调用出卷工具+双向细目表

用户: "这是本次考试各题得分率，帮我做学情分析：选择题75%，填空60%..."
→ 调用学情报告生成器

用户: "帮我把这份教案做成课件，科技风格"
→ 调用课件模板生成器（V2.0新增）

用户: "设计一个信息科技+数学的STEM项目"
→ 调用STEM项目设计器（V2.0新增）

用户: "检查一下这份教案的质量"
→ 调用课程质量门禁检查器（V2.0新增）
```

## 交叉训练集成

本技能与 `it-edu-cross-training`（用户级技能包 V4.0）互补：
- **it-edu-tools V2.0**：提供**可执行的工具**（教案生成、代码批改、出卷、课件、STEM等）
- **it-edu-cross-training V4.0**：提供**角色能力定义**（6个角色的完整知识库和输出规范）

**推荐用法**：同时加载两个技能包可获得完整的能力覆盖。
