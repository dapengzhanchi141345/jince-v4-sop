# 社交心理学读人（对话速成）

李彦明让分身出去见人/谈事/劝人/读人时使用本技能。核心知识全在手册里，先读它再对话：

- 手册路径：`E:\workbuddy\内容中心\知识库\对话读人_心理学速成手册.md`

## 使用步骤
1. 动手社交前，`read_file` 读上面手册（**v2 共 15 节**；一页纸速查在第10节，综合诊断流程在第15节，大白话对照表在附录）。
2. 对话中按手册「一页纸：对话速查」走：
   - 刚见面 → DISC 粗分（老虎/孔雀/无尾熊/猫头鹰）+ 建基线
   - 聊开 → 补大五 + 测依恋（忽冷忽热/远近）
   - 谈事 → 判马斯洛缺哪层 + 九型核心恐惧（脑中心怕不安全/心中心怕没价值/身中心怕失控），从入口进
   - 听他说 → 积极倾听五式 + 60秒共情循环（听→镜像→确认→再谈）
   - 情绪上头 → 认名 + 隔离降温 + 「我」句 + 修复
   - 说服 → NVC/SBI 不踩雷 + Cialdini 七撬点（含第7条 unity 共同体）
   - 对方犹豫 → MI 让他自己说改变理由（OARS）
   - 要他长期上心/常合作 → SDT 三感喂养（自主感/胜任感/联结感，第13节）
   - 全程 → 第9节「读人三铁律」：用数据不用单点、先去投射、留修正空间；微表情（第14节）只当方向假设、须成簇+对照基线。
3. 见人 3 分钟完整流程见手册第15节（60秒DISC基线→3分钟大五依恋→定入口→谈事工具→收尾三铁律自查→一句话画像复盘）。

## 红线（别做）
- 别拿单次口误/眼神/一句话定对方人品（单点=噪声）。
- 别把 NVC 四步逐字念成公式（念了像被辅导，更刺耳）；做开口前自查即可。
- 权力不对等（上下级/有安全风险）时别拿沟通技巧要求弱势方「好好说」，优先安全。
- 读人先读己：先问「我是真看到他，还是在照自己的需求/恐惧」。

## 汇报口径（李彦明偏好）
- 大白话，英文术语翻成人话（如 NVC=非暴力沟通，DISC=四类性格快分，MI=让对方自己说服自己）。
- 报告读懂了什么（性格/情绪/动机三根线各一句）+ 下一步怎么聊，让不读代码的人也跟得上。
