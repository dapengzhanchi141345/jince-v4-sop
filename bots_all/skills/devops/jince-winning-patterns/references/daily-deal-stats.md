# 当日成交四维统计底稿配方（做单复盘/深挖第一步）

适用: 「根据昨天的单子优化做单技能」型任务的第一步——把 MT5 成交史压成可直接下结论的统计底稿。脚本落 scratch 一次跑完(约 1 分钟), 不逐单人肉核。

## 配方
1. **窗**: 「昨天」= BJT 日窗 = `datetime(前一日,16,0,0)` → `datetime(当日,16,0,0)` 本机 epoch(本机时区即 BJT; 详见 mt5-live-read 日窗条)。`history_deals_get(t0,t1)`。
2. **分腿**: 平仓腿 = `profit != 0`(最稳口径, 别依赖 entry 常量); 开仓腿 = `profit == 0`。字段一律 getattr 候选列表取(无 `.price_open`)。
3. **四维聚合**(每维输出 n/净/盈数/亏数, 净降序):
   - **出场机制**: 读 comment 前缀分类——`[tp`/`[sl`/`L24_B0_INVAL`(结构失效早退)/`L24_LOSECUT斩亏`(150min 兜底)/`L24_MAXHOLD硬平`(18h 触顶)。救援类出场(B0/LOSECUT)全亏=进场质量问题, 不是出场机制问题——别把病开在出场上。
   - **币族/资产类**: 品种名后缀定族(JPY/AUD/EUR/GBP/CHF/NZD/CAD/SEK/ZAR/HKD/SGD/MXN); 币系=BTC/ETH/SOL/LTC/XRP/XLM/DOGE/UNI/ADA/AVX 等 USD 计价加密; 股指/个股=TW88/HK50/US2000/UK100/SWI20/GER40/.NAS/.HKG。族级全亏=家族账降档证据(只证 30 天否决门级, 不直接 RETIRE)。
   - **时段**: 平仓时刻折 BJT 整时桶; 找最好窗/最差窗。样本 <10 笔的窗只 OBSERVE 不下闸。
   - **方向**: 多/空各净——⚠ 平仓 deal `.type` 是平仓方向, 镜像陷阱见 mt5-live-read; 统计前必须翻正, 否则多空结论整体反掉。
4. **同分钟批量簇**: 同分钟(±5min)≥3 腿同平仓=同族批量错实证, 直接喂同族批量闸提案。5. 总账行必带: 笔数/净利/胜率 + 剔除实盘腿(魔号 20261105 等 1.0 手)后的练习腿净(0.01 样本口径与实盘腿分开报, 防大单盖住练习纪律)。
6. **交叉源**: 验尸官归档(`postmortem/pm_*.md` 72h 深析)+ 引擎 `live24_trades.csv` 闸标记(SKIP_*) 对齐后, 再写进做单技能; 单源统计不出结论。

## 跨日因子表（亏源定位第二刀: 品系×时段×机制三切 + 桶级 PF）
适用: "不赚钱的再深挖"型指令——单日四维底稿不够, 需 10 天级全量平仓腿按桶切利润因子(PF=Σwin/Σloss)定亏源。窗=`history_deals_get(起始 epoch, now)`, 平仓腿口径不变(`profit!=0`)。
- **切法**: 品系(fam: crypto/JPY族/equity/index/gold/fx, 品种名规则同四维) × 时段(UTC 整时桶: 00h/05-08h/09-12h/13-16h/17-21h) × 出场机制(comment 前缀)。
- **桶级 PF 读数规则(防误判)**: ① 桶 PF<0.5 且 n≥10 = 真亏源(进 kill 窗/否决门工单); ② 毛亏额大但 PF>1(如 FX 重叠窗)= 高波动双向窗, **不动**——砍掉它=砍掉最大利润源; ③ "赢多亏少但赢/亏额比<0.5" = 多小赢少大亏结构坏桶(净 R 为负), 是时段闸候选而非胜率问题; ④ 样本 <10 笔的桶只 OBSERVE。
- **产出落盘**: 因子表 JSON(品系总账+时段 top 亏+机制 top)+ "大神共识处置"(先全网搜对应死法: 假突破/追顶/滑点/时段, 三源交叉才落闸)+ 时段精化工单入 rd_queue(五验前只 OBSERVE 不动执行层)。落 `data/loss_factor_audit_<日期>.json` + 台账 + 状态卡。
- **引擎僵尸判据(配套)**: 跑因子表前先看引擎 stdout 尾——重复 `loop err: name 'X' is not defined` = 主循环每轮 NameError, 进程活但**根本没处理过新信号**(活着的僵尸), 先修变量再谈数据; 进程存在 ≠ 信号链路活着。
