# MT4 观摩/实盘账号 Statement 深度分析（只读任务）

用户给一个 MT4 账号（观摩密码 / 实盘号）要"深度分析/复刻"时，走这条线。铁律：**只读，绝不下单，绝不把客户/他人账号接进金策系统，绝不 kill 已连上的终端**。

## 取数据（唯一正解，别再绕）
- 成交记录**只在服务器端**，本地 `history/` 只有 K 线 `.hst`，没有成交记录。PyPI 无可用 MT4 Python 库。
- **investor/观摩终端一旦你 kill/重启它，就再也不自动重连**（登录态不持久化到 `accounts.ini`）。现象：`history/MagicCompass-Live/XAUUSD*.hst` 的 mtime 冻结在某刻、日志 `09:xx` 后无新 login 行。此时你自挂的 `/i` 导出 EA 拿不到 tick，永远写不出文件 → 30+ 轮空转全废。
- 结论：**已连好的终端别再 kill、别再指望 /i 导出 EA**。直接让用户从该终端导出文件发本地盘：
  - 首选：账户页/历史面板 →「Statement」/「另存为」→ `Statement.htm`（HTML 全表，含 Closed/Open Transactions + 存提款）。
  - 次选：F2 历史订单 → All → 右键「另存为」CSV。
- 用户已说"太慢/别绕弯/赶紧"时，第一动作就是**要文件**，停手别折腾终端。

## 解析 Statement.htm（HTML 全表）
- 每行成交是 `<tr>…</td>`；表头 14 列：Ticket / Open Time / Type / Size / Item(品种) / Price(开价) / S/L / T/P / Close Time / 平仓价 / Commission / Taxes / Swap / Profit。
- **Type 字段分三类**：`buy`/`sell` = 平仓成交；`balance`/`deposit`/`withdrawal` = 存提款/余额；`interest`/`swap`/`credit` 等 = 其他。先按 type 分流，**别把 balance 行当成交算进胜率**。
- colspan 会让一行 td 数少于 14：解析时对每行 `while len(v)<14: v.append("")` 补位，再按下标取列。数字去掉空格/逗号再 `float`。
- 品种会带两个写法（`xauusd` 与 `xauusd.g`），分析时**合并算同一品种**，但报告里点明。
- 入金若全 0 → 这是"账户净变化"不是"收益率"，**别报收益率**；最大回撤要在同一净值口径下算（别把 8 月前打穿负数的老账本并进 8 月后曲线，会把 MDD 算穿成 476% 假象）。

## 深挖必做：高胜率负期望陷阱 & 净利集中度 & 波幅 Regime 闸（2026-10-11 徐总13万笔教训）

**同一维度切 N 刀，别只看整包 WR/PF**：整包 WR 64.5% / PF 1.17 看着"还行"，但拆开立刻见真：
- **高胜率负期望陷阱**：EURUSD 73% 胜率、AUDUSD 76% 胜率，净利却是负的（-501 / -10,376）——靠胜率薄边没扣完成本，**高 WR 品种必须单独看净利**，不能当 edge 学。凡报告里出现"某品种 WR 很高"的，下一步必查该品种净利符号。
- **净利集中度**：总净利 15.7 万，XAUUSD 单腿贡献 16.8 万（=107%），其他 7 品种全拖后腿。**必须报"净利 100% 来自 X% 的笔数/品种"**——剥头皮真身=小单试盘（78% 笔数亏 2.7 万）+ 大单收割（4.3% 笔数赚 16.7 万）。报告要写"这套策略的命根子在哪个手数桶/品种/时段"。
- **持仓时长分桶**：0-1 分钟 8.7 万笔 WR 74.4% 净利 +32 万；拖到 5 分钟以上全桶负贡献。写"命根子持仓时长"。
- **波幅 Regime 闸（趋势/震荡判断）**：按日开价 max-min 分桶，震荡日（波幅≤50）931 天 +15.5 万 vs 趋势日（>50）175 天 -3 千——这是金策最缺的 regime 判断实数 OOS。凡剥头皮策略必查波幅维度，这是可进五验的硬 edge。
- **TP 设置率**：84% 笔数没设 TP，反而没设的赚 12 万 > 设了的 3 万——剥头皮靠"快进快出 + 收盘前强平"，不靠 TP 距离，TP 距离分布无意义。

**深挖后出裁决三条（可学/不可学/口径纠错）**：
- **可学 edge**：波幅 Regime 闸（震荡日开/趋势日停，进 L2 研判层前置门，非单腿，阈值走五验④参数邻域确认）+ 手数金字塔结构（小单试盘+大单收割，对齐现有 pyr 加仓腿 n 不足的问题，过 P2 放大闸才放大）
- **不可学（hard_fail）**：薄边 RR proxy 0.64 < 2.0 出徒线 + 单品种 94% 集中违反 164 分散口径 + **回撤口径要纠错**（原 73.9% 是把某次单日毛亏跟当时净值比的口径错误，逐笔时间序重算=真实 12.8% of 峰值，风控官那条 hard_fail 要重核别误杀）
- **0-1min scalping 结构**：不进 30min 主循环（节拍天然冲突，30min 循环抓不到 0-1min 结构），进研发观察区攒 OOS 样本 + 跟 SH1 本地回测对照

**注入自有系统（不等子岗 429 冷却，主 bot 亲自下场）**：
- trader_brain.py 加 `⑩ 波幅 Regime 闸`（`_xu_vol_regime_check`：读 tick_live 当日 high/low，波幅>50 XAU 降仓 50%，WATCH 模式非硬拒，失败开放放行不误杀）
- 加 `⑪ 手数金字塔`（`_pyramid_check`：≤0.02 试盘区 / 0.03-0.10 中间区 / >0.10 收割区，WATCH 只标注状态不放大仓位）
- 提案 dict 带 `xu_regime_gate` + `xu_pyramid_gate` 字段（mode / threshold / oos_source / regime_scale / state），执行端按此守纪律
- 登记 task_ledger + rd_queue 两条 P1 五验队列（同分母回放 + DSR/PBO 参数邻域 + 品种稳健 + 跟 SH2 时段权重合流）
- **铁律：新 edge 进 trader_brain 默认 WATCH 模式（提权否决门，不单独开仓/不放大），出徒过五验后才改 LIVE（硬闸）。高胜率≠正期望，放大只放大已验证正期望。**

## 切片与分析维度（用户常要"只看 8 月后"这种口径）
- **先问/先看时间口径**：不同月份可能换过策略。用户说"8 月前是另一策略"就 `sel = [t for t in trades if odt>=datetime(2026,8,1)]` 再算，别全量混。
- 全套指标（一次算全）：总笔数/买卖拆分、胜率、PF（毛赢/毛亏）、均赢 vs 均亏比、月度净盈+胜率、连亏/连胜、活跃日数/日均笔/单日最多、亏损日占比、单日最大盈亏、持仓时长分布（均值/中位/分桶）、止损 vs 止盈距离、手数分布（前 5 档）、**按开盘小时 UTC 的净盈 top/bottom**（剥头皮常在欧美盘 14-15 时最赚）、周末 vs 工作日。
- 行为画像定性（大白话）：手数档位 + 持仓中位秒/分级 = 超高频剥头皮 or 趋势；买卖近对半 = 方向随机刷量；PF>1.3 且多数日赚 + 单日最大亏被压小 = 正期望稳健系统。
