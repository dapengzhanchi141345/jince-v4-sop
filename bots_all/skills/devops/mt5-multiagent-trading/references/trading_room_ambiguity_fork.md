# 用户指令双向解读（交易群）

交易指令如「直接开始操作/不用后台模拟」可被读成两个互斥方向（让受闸执行层开始真开单 vs 停掉后台模拟层）时：
- 不猜：一次性 clarify 给具体可执行选项，每个选项写明落地动作；不可逆动作（杀进程、开实单开关、拉真下单层）只在用户选定后一枪执行。
- clarify 超时未答：群里只报「实数状态＋分叉待选」等用户回话，不代裁、不二次追问。
- 判据：选错方向的代价是真仓位/真进程（demo 号也是练手账实数），所以方向歧义优先于「别拖」——问一次不丢人，做反了要重杀重拉。
- 报数规范：状态实读贴实数（账户号/仓数/净值/进程 PID），不口播；账号只报全链唯一号，旧号 0 命中格式进内部文件不入群。
