# MFE 浮盈反转深度解析工作流（"昨天的单浮盈没吃到/能不能抓插针底部"类请求）

用户要"深度解析昨天的单子"或"行情反转时立即出场吃第一波利润"时走此流。产出 = Word 深度报告 + 聊天大白话摘要 + 优化方向派发。全程大白话汇报（黑话只进留痕行）。

## 步骤序
1. **先核数据源再动手**：读 `data/live24_trades.csv` 前按 (sym, ticket, reason, 10min 窗) 去重——引擎平仓日志会被幽灵持仓重复记（同 ticket 几十~几百行），不去重的统计是脏分母；去重后对 MT5 `history_deals_get` 实读证伪（该窗 0 deal = 幽灵实锤，先修引擎侧 10min 抑制再统计）。
2. **配对平仓单**：按 position_id 把开/平 pair 起来（MT5 读 deals 先定 entry 常量：平仓真实盈亏只在 entry==3/4 行，见 SKILL 平仓归因条），取每笔开/平时刻、入场价、出场价、净盈亏。
3. **算 MFE（最大浮盈）**：对每笔取开~平窗口内 M5 K线（`copy_rates_range` 按该窗口，numpy void 数组取字段 `arr['high'][-1]` 族写法），多头 MFE=max(high-entry)、空头 MFE=entry-min(low)，转美元 = MFE×手数×合约值。MFE>0 但净亏 = "浮盈反转亏"核心样本。
4. **分品种族分层试尾切（先全样本同分母，再族级分层复核）**：对 MFE>0 样本按 0.5x/0.6x/0.7x MFE 假设回切，看族级净效果——分品种（币系大波动族 vs 外汇小波动族）分别看，族级净正才立候选规则；族级净负（常见）= 结论是"别切"，同样是有价值的判读，别只报"能切"的好消息。**⚠ 子族选择效应陷阱（11-11 实证）：族级/单族（如只看大股指 5 笔）的回切结论必须拿全部 MFE>0 样本（币系+外汇混合 9 笔级）同分母复核一遍——11-11 实例："固定 60% 回吐砍"在指数族 5 笔上判"更好"，全样本 9 笔一算整体微亏（+34.46 vs 现状 +35.36）= 子族结论是选择效应不是 edge，弃。族级数字只能当线索，全样本同分母才是闸前分母。**
5. **分两种病再开药**：①真反转（开对方向、行情掉头）→ 尾切类候选（分品种族）；②开仓即错（入场后 MFE≈0、一直浮亏）→ 优化点是入场质量（如插针/二进类），不是出场。两病药方不同，报告分开写。
6. **闸候选同分母验后才进**：尾切/插针/二进类任何"进实盘"候选 = 放大风险 → 走五验（references/leg-polish-five-test.md），不过闸只做影子观察腿（0 真实开仓、只记"若当时做了会怎样"）；负期望腿退役 → 研发五验裁留。先报"影子腿起步、过五验再真实"的阶梯，不直接承诺实盘收益（历史回测≠未来收益）。
   - **棘轮/追踪类（ratchet trailing）= 本流首选候选族（11-11 实证 3.29x 胜出）**：固定 60% 回吐全样本微亏弃；ATR 动态砍 2.7x 居次；棘轮（峰值 R≥0.5 解锁、每 +0.5R 上移一档、回吐穿峰值-0.5R 即砍）同分母 +116.59 = 3.29x 现状（XPT 型"开仓即错"单还能扭亏）= 胜出。棘轮语义 = "吃第一波自动锁利 + 趋势续走继续吃 + 真反转一档内砍掉"，正好对应用户"反转及时出场+二单看大趋势"诉求；"二单"另走影子观察腿，两件事分开报别混。**落地纪律：新出场策略一律引擎侧 dry-run 旗标先跑（RATCHET_LIVE=False 式，只记"该砍时刻+能多吃多少"0 真实动作）→ 派 strategy-rd 进五验（OOS 30 样本+5 折走查+扣滑点净期望≥1.0）→ 过了才翻开关转实单；不过=留 dry-run 攒样，绝不凭盘内小样本回测直接开实单。**
7. **交付三件**：① docx 报告（docx 技能：封面+目录+彩色表格+MFE 曲线图+页码，存 `E:/workbuddy/内容中心/交付/<名>_YYYYMMDD.docx`）② 聊天层一屏大白话摘要（两种病+数字+下一步，不贴 docx 内容进聊天）③ 优化方向总线派发（退役→strategy-rd 五验 / 尾切→回测过闸才固化 / 影子腿→research 台账攒样），派单后报"已派 X，等 Y 裁"。

## 坑
- **M5 K线取价时区**：tick/K线 time 是 EET 墙钟 epoch（比 BJT 快 ~2h），开/平窗口对齐先做时区修正（SKILL "tick 停更"条同公式），不然 MFE 窗口错位全废。
- **小样本不下实盘结论**：单族 MFE 反转样本 <30 笔时只给"影子观察"不给"固化参数"；样本够（≈≥1000 事件）才进五验。
- **报告数字以去重后为准**：报告里"N 笔"必标"已去幽灵重记"口径，防下游拿脏数复算打架。
