# 外部正向候选/里程碑证据受理闸（进化营 evo_milestone 族）

**触发面**：总线（AgentCommons inbox）收到 `evolution_milestone` 件，正文形如「进化突破：<品种> 出现正向候选 fitness=N 样本=M（本地回测，待人工复核）」（来源 evo_24x7_supervisor / 进化营 24x7 循环）。

**核心规则：fitness 值单独出现 = 信号，不是证据，绝不直接放行。** 里程碑自带"待人工复核"字样，五验/同分母/OOS 纪律（SKILL.md 外部实盘 OOS 校准节第 2 条同口径）仍全适用。处置=当日回执，不回=滞留（"CR/回执类当日补回执"纪律）。

## 回执索要五件套（缺哪件哪件不过）
1. **候选全参数集**：策略族/入场条件/SL/TP 规则/过滤/时间窗（可复现=证据，黑箱 fitness 数=不可核）；
2. **同窗实测指标**：该回测卷区间 + n/PF/WR/最大回撤/盈亏比（同分母=同窗同品种同口径，子集高胜率=选择效应不算 edge，用户既有裁定）；
3. **基线同分母对照**：与在库基线（7 品种口径）对照表——候选 vs 对照腿在**同一事件全集**重打分；
4. **OOS 独立段**：未参与调参的独立数据段；**样本数若含调参前卷，此件为必给**（回执里点名"n=M 若含调参期=选择效应嫌疑，④必须给"）；
5. **回测落盘**：CSV/报告路径 + 随机数种子（对方实盘真值只认 `E:\AgentCommons\shared\live_state.json` 契约，本地 CSV 路径给出来才好核）。

## 判定出口（三选一，全部留痕）
- **五件套齐 + 过五验口径**（样本量/同分母 A-B/品种稳健/参数甜区/walk-forward，SKILL.md 五验节）→ 登记 `rd_watchlist.json` status=OBSERVE + 0.01 手样本腿纪律（L4 0.01 观察腿口径：免事件降档+12h 必平+30 笔同分母复测再裁），回执"已进样本道"；
- **不过（缺 OOS/子集冒充/无对照）** → REJECT 留痕（`rd_ledger.json` five_gate:false 条目 + 一行原因），回执说明缺哪件、补哪件可重提；
- **部分齐** → 挂 `rd_queue.json`（priority 排进 strategy-rd 循环）标 partial，回执"已挂队列，补齐后自动复验"。

## 回执写法（总线 workbuddy 收件箱，CR 件）
- 一条 json 落 `E:\AgentCommons\bus\inbox\workbuddy\`（from=hermes-chief, kind=CR, in_reply_to=里程碑件 id），正文=受理✓+暂不放行+五件套清单（①②③④⑤ 逐条列，明写哪件必给）+ 判定出口三选一口径 + 时间承诺（当日/下循环复验）。
- 回执里不复述任何账户/密钥信息；本地 CSV 路径类文件位置信息可给。
- 判完报李彦明一行：候选是什么（大白话）/ 卡在五验哪条 / 0.01 样本腿还是 REJECT / 下一步谁负责。

## 同族扩展（同一闸，不同皮）
- 进化营「做单思路」里的**新思路条目**（去重后 N 条）与「融会贯通开单建议」单点信号 = 候选弹药库（mt5-manual-trading-practice 择优五问铁律同口径）：信号≠放行，过五问+0.01 纪律才开；本文件的五件套只用于**声称"正向候选/突破/fitness"级别的里程碑件**（证据要求更严）。
