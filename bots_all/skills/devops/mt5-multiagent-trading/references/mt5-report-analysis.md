# MT5 客户账户报告(HTML) 深度分析 SOP (外部账户只读, 吸取策略精华)

触发: 用户发来某账户的 MT5 交易历史报告文件(`ReportHistory-*.html`, UTF-16) 要"深度分析数据 / 吸取精华 / 看这个策略行不行"。这是**离线只读**任务(区别于 `references/mt4-statement-analysis.md` 的 MT4 在线拉数): 不动 MT5、零交易动作、密码不出现。

## 解析步骤 (踩过坑的实数路径)
1. **编码**: MT5 导出的 HTML 是 **UTF-16 LE**。`open(rb).decode("utf-16")` 一次解完; 直接当 UTF-8/GBK 读全是乱码。
2. **两段表别混**: 报告有两类行 — ①持仓(已平仓)表: 品种+方向+开/关时间+SL/TP+盈利; ②成交明细表: 每笔拆成 in/out 两行(开仓行净值为0, 平仓行带净值)。逐笔统计**以持仓表为准(同分母)**, 成交明细只补"挂单/撤单行为"。
3. **列错位坑(持仓表)**: 行里有个 `<td class="hidden" colspan="8">` 把手数/开价/SL/TP/关时间/关价 8 列压成 1 个空 td, 所以解析后手数在 tds[5] 不在 tds[4]。**判定持仓行 vs 成交明细行**: 成交明细行第 4/5 列有 `in`/`out` 字样, 持仓行没有; 且持仓行的"关时间"列是完整时间戳。
4. **交叉验账**: 逐笔求和(总盈利)必须≈官方统计段的"总净盈利"(差=库存费/佣金), 对不上说明列错位解析错。官方统计段(盈利因子/胜率/最大回撤/最大连胜)从"结果"段按标签抓 `<b>` 值。
5. 落盘 `data/shanghai_parsed.json`(逐笔 + 官方统计 + 分时段/分品种), 可复跑。

## 策略精华 5 维提取 (同分母, 全实数不凭印象)
① **时段权重**: 按开仓钟点分桶(亚盘/午后/欧盘/美盘) 各桶净赚+胜率 → 看主力段在哪。② **持有时长分布**: 中位/P75/最长 + "<2h 强平赚多少 vs >=2h 赚多少" → 判剥头皮还是扛单。③ **大小单结构**: 大赢家 top5 + 唯一亏单明细 → 判"靠高胜率堆 vs 靠单笔博大"。④ **纪律实数**: 挂 SL 几笔/挂 TP 几笔 → "手动秒平"型 vs "固定止损"型。⑤ **手续费/库存费总账** (负库存费=扛单跨夜成本)。

## 吸收铁律 (外部账户高胜率的可复制性怀疑)
- 别人实盘 97% 胜率 **不等于** 策略本身正期望: 可能是"行情配合 + 小仓位 + 及时止盈"三者叠加。吸取时**走五验 0.01 攒样本, 不直接放大手数**; 把可复用的**行为纪律**(如"2h 不兑现就平/主力时段/SL 挂法")抽出来进五验队列, 不把"+32%"当未来收益承诺。
- 报告段口径: 有提取/入金流水的, "+X%"是**报告段**不是全程, 汇报时标清楚。
- 对客/群汇报丑话: 历史回测≠未来收益; 这是别人账户, 只学思路不碰他的单。
- 实例(2026-10-08 81223578): 10 天 100 笔净赚 +3305(+32%, 段口径), 97% 胜率靠"2h 短打 + 43/100 挂 TP + 仅 1/100 挂 SL 手动秒平", 主力段=亚盘午后(12-15)+欧盘(15-19), 美盘仅 4 笔。吸收 3 条进五验: ①黄金 2h 短打腿 ②时段权重进开评 ③亏单 3h 秒平纪律。
