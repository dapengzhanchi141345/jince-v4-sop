# 对客/客户演示交易材料 — B 档红线 (用户令"给客户演示开单", ops-manager 定边界)

## 触发场景

## 铁律 (B 档口径, 全群焊死)
**方向词一个字不进对客物料。** 可发的 = 方法论 + 风控参数 + 框架, 绝不可发的 = 任何"该买/该卖/该在 X 价位挂 X 单"的方向判词、真实下单票号、"点头我就挂"这种代下单承诺。原因 = 荐股红线: 对客给方向 = 代客决策 + 责任, 违反"实盘最小影响/不代客户下单"。

### 可进对客的 (方法论, 用假设例证不指方向)
1. 开单 7 步流程: 判 regime(ADX>25 趋势/≤25 震荡) → ATR 算 SL(趋势2.0×H4-ATR/震荡1.0×, SL距≤2.5×ATR) → 算 TP+RR(趋势≥2/震荡≥1.5, 不达标不开) → 手数=净值×1%÷止损点(先定亏多少再倒推量) → 三道风控闸(日亏10%熔断/连亏3笔冷却24h/每品种日≤3单+总督控总热量) → 挂条件单+30min状态机(>3.5×ATR 幽灵单撤) → L1-L6 离场(只平做错的, 方向对的移 SL 到结构位)。
2. 用"一个假设的 EURUSD 趋势单"当例子讲方法论, 不指真实方向、不用真实票号。
3. 演示账号用 demo 练手号 60137964, 永不碰客户/实盘号。

### 必附三句 (合规)
① 这是方法论演示, 用模拟号, 不构成投资建议、不指该买卖哪个方向;
② 方向由客户自己判断, 我不代下单、不替客户操作账户;
③ 历史回测≠未来收益, 任何策略不保证赚钱, 亏得起再下(单笔 1%)。

### 红线 grep 自检（出街前必做，命中要读语境不要只数数）
生成对客/呈报物料后，跑一轮关键词 grep（方向词 4226/4143、收益承诺 保证赚/赚/给力/比肩、实盘数据 91笔/OOS/净值、代客 代客理财/推荐、点位/零风险）。**命中≠违规，逐条读上下文分两类**：
- **合规语境（否定式/警示式）不算命中**：如“黄金交易不存在「零风险」，任何说「没有风险」的都是违规”“目标是控制封顶风险，而非消除风险”“任何『保证赚钱/零风险』的说法都是骗局”——这些是把红线写进文案的免责表述，放行。
- **正向承诺才算命中（违规）**：“保证赚/能赚/稳赚”“你看多到 4200”“代你下单/代客操作账户”。这类一个字都不能留。
判完在报告里明写“红线 grep N 命中，其中合规语境 M 条（列出）、正向违规 0 条”，交 risk-officer L4 复检确认，过才把草稿翻正式。内部实数（OOS/净值/点 4226/笔数）一律 0 进对客稿，内部完整研判只留内部版。

## 金策 24h 回测火力: 证伪也是成绩 (主持人丑话)
用户"火力全开 24h 不停回测 快点赚钱"时, 最快路径 = **只放大已验证正期望 + 并行攒 30 笔 OOS**, 不是跳档放大未验证。回测跑得越勤 = 越快证伪一批亏钱腿, 这是系统健康不是失败 (实例: ORB60 币圈正期望腿搬外汇双时段 = REJECT 0/6 同号, 拦掉一条会亏钱的腿, 是好事)。把"出成绩"挂在"回测变多"上错位, 真正成绩=净值转正+30 笔 OOS 同号。丑话必说: 无策略能"务必赚钱", 历史回测≠未来收益。
