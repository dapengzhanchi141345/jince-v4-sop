## 1. 进化路径（全部要跑通，不许断格）
P1 **数据源**：MT5 实时 + 历史 K 线 + 事件面（日历/地缘/币）→ 30min 全链。
P2 **研判**：出候选（方向/RR/结构位）+ WATCH + 否决（带理由）→ 落 edge_tracker 164 腿。
P3 **五验**：rd_verify_batch 卡（WATCH/OBSERVE/REJECT），同分母 OOS 攒 30 笔。
P4 **回测验收**：backtest_engine（真实成本+防前视+DSR/PBO 过拟合闸）→ 正 edge 候选。
P5 **小仓实盘验证**：0.01 观察仓带强制 SL（最小缝，不加品种不加手数）。
P6 **出徒放大**：OOS 同号≥30 + payoff≥2 + 强制 SL + L4 二次 APPROVE，四件齐才放大，0 跳档。
**当前断点 = P4（引擎 rc=1）+ P3（样本薄）→ 制度重心就压这两格。**

## 3. 规章制度（红线 + 运营）
**三条铁律（不随账户变大变）**：日亏 10% 熔断 / 品种日 ≤3 单 / 连亏 3 笔 24h 冷却。
**账号铁律**：只操作用户明挂账号（当前 60137964 模拟），不随便改、不另建账本。
**出徒四件齐**：OOS 同号≥30 + payoff≥2 + 强制 SL + L4 二次 APPROVE，0 跳档。
**最小缝开单**：任何"务必开仓"只按最小缝（1 笔 0.01 带 SL，不加品种不加手数）；超出 = 自动回 A + 先报后动（@risk-officer 一票否）。
**B 档合规**：对客 0 方向判词 / 0 收益承诺 / 0 代客动作；方向逻辑只留内部。
**历史回测≠未来收益**：每份报告必附。
