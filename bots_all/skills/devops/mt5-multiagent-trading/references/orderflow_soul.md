## 机构订单流·下单四步固定流程（每次下单决策前必跑，跑完留痕才下单——不跑=流程违规（L4 可点名））

1. **识机构行为痕迹**（H1/M15 上找谁在干活）：成交密集区（volume profile/成交峰值）· 等高低/流动性池位置 · 扫损反走（stop hunt：插针穿前低/前高后收回 = 机构扫流动性后反向）· 量峰异常（K 线量分位 ≥P90 = 大单痕迹）· 价格钉在密集区上方/下方（吸筹 vs 出货形态）。
2. **订单流视角定方向与位**：机构吸筹 = 密集区上方缩量横盘不破（Seiden：转折伴随低量、失衡越重成交越少）→ 回踩密集区下沿进多；机构出货 = 密集区下方量增反抽不过 → 反抽进空；流动性池扫后 = 单点破位追趋势、扫损收回反做。**Seiden 低量转折方向疑点（20:56 进化营通报）校准前，密集区验证用「量不增价不跌」保守判，不照 3:1/密集区激进口径上线。**
3. **时段+量交叉验证**（两条独立证据链才放行）：时段闸（徐 DST 13 万笔大样本：01/18 时最赚、16 时唯一负净；deco 385 笔时段结论已被 R6 同分母交叉证伪、只作假设待 L1 回验）× 量代理（该 K 线量分位低量转折/高量突破）；与步骤 1-2 指向不同 = 不下单（冲突留痕）。
4. **留痕+回验闭环**：每笔决策把四步判断写成大白话行落 discussion_log（tag=`订单流四步`：谁在吸筹/流动性池在哪/什么时段/量什么分位/放行理由），L1 tick 管道（copy_ticks→Delta/CVD/VolumeProfile）跑通后逐条回验判断对错——R11：回验无差异证据 = 流程没生效。**首单实跑 = NFP 静默窗结束后首个美股批（博通/英特尔；四步判断已留痕 discussion_log tag=orderflow_4step，券商端 close-only 时顺延不重判，复跑直接复用留痕判断）；复盘时核四步留痕齐不齐，缺一条报 L4。若下单前实读 trade_mode 仍 close-only，本批留痕后顺延明批，不硬怼拒单。**
