## 定性（最重要，别再读错）
**对冲锁仓流，不是「无止损裸奔」。** 账户是 MT5 Hedge（对冲）模式：买卖单并列独立持有，平仓时系统按净差额结算。报告里的逐笔毛利 ≠ 真实风险敞口，真实敞口 = 净头寸（买手数合计 − 卖手数合计）。

## 操作节奏（大白话）
1. 小仓 0.05/0.1 手跟黄金趋势走，一天 8~10 笔，同方向价格每隔 1~4 美元加一单（顺势加仓）。
2. 方向反了 → 不砍仓，开一笔反向对冲单锁住（净头寸归零），保留浮亏。金价怎么跑都不再亏。
3. 锁住后保留浮亏锁，等新趋势方向明确，再加顺势单。新趋势对了 → 浮亏被新趋势盈利对冲释放；继续反方向 → 继续加对冲，净头寸始终受控。
4. 全程靠方向判断准确率吃饭。

## 真实风险点（修正后，勿再用「裸奔」说法）
1. 浮亏锁长期挂着 → 持续吃库存费（锁越久 swap 越高）。
2. 方向错且长期不回头 → 浮亏锁在 A、新趋势单锁在 B，单边大幅走时两头锁仓成本（点差+库存费+资金占用）持续扩大。
3. Hedge 双向资金占用翻倍（平均每笔名义约 3.4 万 USD），实际杠杆比表面高。
4. 靠人盯盘，决策全手动。
5. 对方向准确率依赖高，连续判断错则锁仓成本累积。

## 公式化研发方案（落到金策 16 部门）
- 模块一 净头寸计算：net = 买手数合计 − 卖手数合计，开单前算。
- 模块二 顺势加仓：net 与趋势同向 且 价格推进 > 阈值(1~4美元) → 加 0.05 手，每组 ≤ N 笔。
- 模块三 对冲锁仓触发：价格反向突破阈值 且 net≠0 → 开反向单使净头寸归零/减半（锁浮亏）。
- 模块四 锁仓释放：新趋势确认 且 顺势单盈利 ≥ 锁仓浮亏 → 释放锁仓结平该方向。
- 风控闸（risk-officer）：资金占用 ≤ 账户 X%（Hedge 双向加总）；锁仓过夜 ≤ M 小时超时降手/释放；日亏 10% 全平锁仓 + 24h 冷却；留痕 hedge_log.json + veto_log.json。
- 回测验收（strategy-rd+回测岗）：≥6 个月黄金 M5，同分母对比现有策略；看胜率/回撤/夏普/swap 成本；门槛=锁仓后净头寸受控、无满仓单向裸敞口、夏普>1。
