# P4 出徒加速 (用户"快点出徒"时的 triage + 提速 SOP)

用户反复要求"务必快点出徒"。不是跳档, 是先定位卡在哪条、再用已验证正期望腿并行攒 OOS 把闸门开掉。

## 第一步: 判哪条卡 (先读实数, 不嘴说)
读 `E:/GoldstrategyEngine/data/meta_evolution.json` 各腿 stats (n_total / wr / expectancy_R) + 当月 P4 五标准现状:
- (a) 净值正且回撤<8% — 看净值曲线 + governor 峰值回撤
- (b) 分盘胜率+RR 达阈(趋势≥2 / 日内≥4) 且样本≥30 笔 — 看各腿 n
- (c) 连续 2 周零系统性故障 — 看 auto_cycle.log 故障行
- (d) 风险合规(无马丁/无超 3 单/无裸奔) — 看 risk_freeze_state + veto_log
- (e) 边衰检测无潜伏异常腿
最常卡的是 **a(净值没转正) + b(样本<30 笔)**。先把哪条卡报出来, 再谈提速。

## 第二步: 并行攒 30 笔 OOS (WATCH 腿毕业提速, 已载规则)
- 靠单时段串行攒 30 笔要半年; 提速=**同一腿跨不相关时段(伦敦+纽约) × 多品种并行攒样本**, 单笔风险不变, 总风险由组合总督(meta_evolver.apply_to_plan)总热量封顶, 对照基线=不加时段的单腿(同分母)。
- **只加速"唯一已过五验的正期望腿"**(实例: ORB60 日内腿, 回测 n=8970 exp_R +0.333R, 唯一 VERIFIED 腿)。未过五验的腿/猜想不进放大线。
- 若目标腿在**币系线且币系冻结桥生效中**(至 11-02 NFP 生死测), 提速走"冻结不影响的那条线"(如把日内腿放到外汇 T2 线攒样本)。**外汇 T2 口径必须独立同分母, 不拿币圈回测口径套外汇。**
- **绝不擅自解冻币系冻结桥** — 解冻是 @risk-officer 的 L4 权, 主持人只出排期+派单+风控官复核, 不自己解闸。

## 第三步: 顺序铁律 (放大排在 OOS 之后)
1. **放大仓位(0.5×→1.0×)永远排在 30 笔 OOS 同号之后** — 放大未验证=爆仓(fam6 马丁已证: 正期望腿+马丁 0/50 打不过不加仓基线, 负期望腿+马丁=加速爆仓)。OOS 没攒够、没同号, 不动仓位。
2. 新学的预测门/构造(厂商文章宣称的准确率数字 = **待复验假设, 不是已验证 edge**)并进同批五验, 但**默认只做否决门/看板提示**, 同分母 A/B 打平现 baseline(扣 0.25R 滑点 + 3 段 walk-forward 同号)才提权 — 同"高胜率≠正期望/裸结构只做否决"族。
3. 每条新构造注册进 `rd_verify_batch_*.json`(PENDING/WATCH/REJECT), @strategy-rd 出 polish.json, @risk-officer 独立复核同分母没被破坏, 周五周会念实数销格。

## 汇报口径 (给 @user 的大白话)
先摆 P4 哪条卡(实数), 再给"两条腿并进"排期(①验证腿并行攒 OOS ②攒够同号后放大仓位拉净值), 末句必带 **"OOS 攒够前不动仓位 + 历史回测≠未来收益"**。
