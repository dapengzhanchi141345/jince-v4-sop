# 开单建议类件处置（进化营 V4.1/V2 快照入 bus，执行层授权直挂）

进化营侧约 20min/拍投「融会贯通开单建议 V4.1」（A/B 类判定 + 逐条限价/SL/TP + 区质量 + depth + 逐条报价时刻）与「做单思路 V2」（新思路清单）。chief 执行层照此直挂限价单。流程：

1. **读全件**（判定行 + 逐条点位/质量/depth），不照单全收。
2. **去重先于挂单**：同品种同点位已挂（对比 `live_state.json` orders 段）= 不重复挂；对方把已挂单移入 B 类/掉出 A 类（价格未回区）= **原限价单维持不撤**（GTC 有效 + SL/TP + 12h 红线兜底，回区即成交）——撤单只走 L4 口径，不跟对方快照节奏。
3. **区质量噪声线 0.05**：质量 <0.05（含负值）= 执行层风控闸拒单（需求区失效/噪声）。判定自洽声明要写在回执里（拒的/过的各例质量值对摆，证明非逐单随意）。质量回正（≥0.05）下版重呈即挂，不追不催。影子链同向 ✓ 不改变质量闸（区弱 + 同向信号仍不进）。
4. **魔号选择**：美股常规腿 = 20261105（美批 + 12h 红线 = 次日 22:20 前平）；0.01 样本腿 = 20261106（攒样本口径，与常规腿分开挂）；live24 标准批 = 30261103。
5. **挂单工具**：ATE python `mt5.order_send`（BUY_LIMIT/SELL_LIMIT + SL/TP + GTC + magic + comment 标来源如 `V4.1A-DECO11-chief`），retcode=10009 才成；挂讫读 `live_state.json` 确认写侧含该 magic（yushi 写真值源）。
6. **回执 bus 双写**（`E:\AgentCommons\bus\inbox\workbuddy\` + `outbox\hermes\` 同文）：逐条注明 挂讫(单号) / 已挂不重复 / 拒(原因+门槛声明) / 维持不撤。同内容后续快照只发「复认」短回执（不重复全文，防刷屏）。
7. **V2 新思路**：触发信号距当前 >2h = 不直接挂（旧信号）；只把质量榜期望为正的（小样本）注册进五验攒样本，期望 ≤0 不进。历史回测≠未来收益。

## 回执模板（逐条处置 + 复认两档）
- 逐条处置件：`A类N条处置讫: ①X=已挂(单号)不重复; ②Y=挂讫(order…, magic…, 三件套+12h红线); ③Z=拒(区质量<0.05噪声线, 门槛自洽声明: 拒例/过例质量值); B类M条观察认; 在仓N口径认`。
- 复认件（快照未变/重投）：`复认: 0新挂0撤单, 拒单维持, 已挂单保留, 口径无异议`（一段话，不重列明细）。

## 易错点
- 对方「判定 A类N条」≠ 可全挂：逐条过质量闸（A 类里混着负质量单）。
- 已挂单掉出对方 A 类 ≠ 要撤（撤单是 L4 口径，信号未反转只回踩等待）。
- 挂讫回报李彦明用大白话：品种中文名 + 进场条件（回落 X% 才进）+ 风控兜底（三件套/红线时刻），不报 magic/RR 黑话。
