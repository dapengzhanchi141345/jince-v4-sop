### Risk discipline the user MANDATES (encode exactly, do not "helpfully" tighten):

### Flawless gate (user iron law: 每个技能必须打磨到无瑕才能用)
- **Every new construct / leg / parameter change goes through the 5-test polish BEFORE wiring into the live path:** (1) sample ≈≥1000 events, (2) same-denominator fair A/B (every grid cell re-scored on the identical full event set; Δ in absolute exp_R + two-proportion z-test), (3) symbol robustness ≥4/6 same-sign, (4) parameter sweet spot (no sign flip between adjacent cells), (5) walk-forward 3 segments stable. - **All-negative grid ⇒ stop new postings, not "keep current params".** If every grid cell is negative-expectancy (best exp_R < 0 on the shared denominator), the leg enters OBSERVATION MODE: a leg flag (e.g. `RANGE_LEG_VERIFIED=False`) suppresses candidate generation while existing pending orders/positions stay managed by `manage_positions` (fail-open). Re-enable only after a future re-test passes the gate.

## P1 风控清理标准流程 (2026-09-27, "先把模拟账号做好" 严格 SOP)
