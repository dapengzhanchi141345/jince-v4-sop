## Cialdini 六条 → 交易客户用哪几条
- **权威** = 亮五验/同分母/回撤曲线证据(比"稳赚"可信)。C型给数据, D型先给结论。
- **社会认同** = 公开看板真实净值/复盘给客户看,"大家都看得到"。
- **互惠** = 免费看板/专栏当样品, 先给价值再谈付费。
- **稀缺** = 定制复盘"每期只带 N 个", 机会难得但不编假时限。
- **喜好/承诺一致** = 建好感+让他在"要纪律不要暴富"上先点头, 再往付费走。

## MI(让对方自己说服自己)
嘴上"帮我赚大钱" / 心里"别让我亏得难看、要心里踏实"。用开放问("你用工具最烦什么?")+反映("听起来你要的是可控, 不是赌大")让他自己说出改变理由 — 比你说"我不保证赚钱"有力。转化钩子: 把"不保证赚钱"翻成优点"**我不拿话术骗你, 我拿回测和纪律对你负责**"。
