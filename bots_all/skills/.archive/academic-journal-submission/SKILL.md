# 学术期刊投稿与拿奖（验真 → 官方直投 → 拿奖路径）

本用户（一线信息科技教师，目标在山东教育类期刊发表并冲教学成果奖）反复要"投稿/拿奖"。核心是非显而易见的防坑顺序，不是怎么排版论文。

## 铁律（每条动手前必守）
1. **正规省刊投稿免费，绝不预付"代投费/版面费/保过"**。收到代投机构群发的"红榜/过审率高/即将满版"图，一律先当催收钩子处理，不转账。
2. **第三方"官网投稿"入口多为镜像站**（自认"非杂志社官网"）。只认期刊社版权信息页/主管主办单位官网能查到的真实邮箱与系统，查到才投，查不到就停，别发给代投。
3. **稿件实证内核落在用户真实资产上**（教学系统、题库、实践数据），不编数字；没跑出来的效果留"前测/后测回填"口，诚实声明样本与周期有限。
4. **论文 ≠ 直接拿奖**。职称评审看"代表性成果"（教案/课题/论文均可，不唯论文）。真正的奖走教学成果奖 + 全国性论文评选。

## 步骤（按顺序）
1. **逐本验真**：对每本被推荐的期刊 web_search 查 CN/ISSN、主管/主办、收录（知网/维普/万方）、影响因子。区分"真省刊"与"偏人物/名家、普通一线教师命中低"的刊（后者不冲量）。
2. **识别代投话术红旗**："过审率高/即将满版/提前交钱保过/省教育厅认可红榜"＝催款钩子。向用户点明防坑。
3. **找官方直投渠道**：杂志社官方邮箱/官网投稿系统，交叉核验（爱科学网/期刊社版权页/主办单位官网各查一遍）。记入交付文档，投前再核一次。
4. **写投稿稿**：一稿多投——主投命中率最高的省刊（对口一线教师）→ 保底刊（好中）→ 学术精修版冲质量最高刊。按各刊体例（字数/栏目/学术腔程度）各出一版，共用同一实证内核。
5. **排拿奖路径**：论文发表→登记代表性成果（职称）→ 以"N 年实践"为底申报省级教学成果奖（二等奖要求 2 年以上实践检验，特等/一等 4 年）→ 同稿投全国级论文评选涨背书。
6. **缺信息就停一步问用户**：投稿需真实单位名/职称/联系方式，这些只能用户提供，不要编。

## Pitfalls
- **别把代投机构给的刊号直接当可信**：刊号可能真，但"过审率高/即将满版"是编的。验真只信主管主办单位官网。
- **别在效果数据上编数字**：用户要"深度记忆"且诚实，编了会被复核抓出（统计同分母铁律同源）。留回填口最稳。
- **镜像站邮箱陷阱**：网上搜"××杂志社官网投稿"命中的 xueshu/qk580 等是第三方整理站，自认"非官网"。直接咨询杂志社才稳。
