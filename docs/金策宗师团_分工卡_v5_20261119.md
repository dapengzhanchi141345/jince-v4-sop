## 三、交棒规则（跨岗只走工单，不直接改）
- 参数官发现哨常量漂移 → rd_queue（owner=执行岗）→ 执行岗改脚本 → 参数官 30min 复检闭环
- 验尸岗发现参数问题 → proposals/ 补派 rd_queue（研发岗五验）→ 研发出裁定 → 参数官写表
- **锁利事件对账路径（v5新）**: 持仓消失/异常平仓 → 验尸岗先查守护日志（平仓价==new_sl 且有"锁利"行=设计内正面事件，不立单）→ 无对应行才立 P1（取证=验尸，定位平单方=研发，合规漏登记=执行岗补账）
- **参数表写冲突路径（v5新）**: 参数官重写后表回弹=竞争写侧 → 研发岗定位（mtime+内容指纹+进程归因）阻写 → 参数官独占重写 → 开新波前必再核表=spec（翻过的表≠还在值上）
- 任何岗改参数表=越权，留痕追责（参数官哨检出=报李）
